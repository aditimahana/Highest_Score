# 📊 Student Score Analyzer

A simple Python program that finds the highest score in a list of student scores.

This project is part of **Angela Yu's 100 Days of Code: The Complete Python Pro Bootcamp**.

## 📌 About the Project

The program takes a predefined list of student scores and iterates through each score to identify the highest value.

It starts with a `max_score` variable set to `0`. Using a `for` loop, the program compares each score against the current maximum. If a higher score is found, `max_score` is updated.

At the end, the program prints the highest score in the list.

## 🛠️ Technologies Used

- **Python 3** – the programming language used to create the program.
- **Lists** – to store multiple student scores.
- **For loops** – to iterate through every score.
- **Conditional statements** – to compare scores and determine whether a new maximum has been found.

## 📚 What I Learnt

Through this project, I practised several fundamental Python concepts:

1. **Lists** – storing multiple values in a single variable using square brackets `[]`.
2. **For Loops** – iterating through each element in a list without manually accessing every value.
3. **Conditional Statements** – using `if` to check whether a score is greater than the current maximum.
4. **Comparison Operators** – using `>` to compare numerical values.
5. **Variables and Assignment** – storing and updating the highest score using `max_score`.
6. **Maximum Value Algorithm** – understanding how to find the largest value in a collection through iteration.

## ▶️ How to Run

1. Make sure Python 3 is installed.
2. Clone this repository or download the Python file.
3. Open the project in your preferred code editor or terminal.
4. Run the following command:

```bash
python main.py
```

5. The program will display the highest score:

```text
199
```
